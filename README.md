## 🎓 Thesis / Current Research

* **Shadowing and Mirroring Microservices Communication:** Designing a microservice-based shadow traffic monitoring and anonymization framework.
* **Focus:** Asynchronously mirroring real data traffic to a test environment using an NGINX API Gateway. The project features GDPR-compliant, real-time anonymization of personal (PII) data, and the automated comparison of responses between production and test environments.
* **Status:** The Docker-based containerized architecture, privacy challenge analysis, and software specification (Privacy-first pipeline) are completed. The implementation and testing phase of the anonymization component and monitoring system is currently in progress.
